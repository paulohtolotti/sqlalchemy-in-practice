# SQLAlchemy in practice

Repositório de estudos da biblioteca SQLAlchemy, baseadas no livro SQLAlchemy 2 In Practice
de Miguel Grinberg.

Referência online: https://blog.miguelgrinberg.com/post/introduction-to-sqlalchemy-2-in-practice

## Como rodar

O banco de dados pode ser construído executando o arquivo docker-compose.

```bash
docker compose up .
```
